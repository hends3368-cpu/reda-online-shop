# Reda Online Shop

An ecommerce website built with **HTML, CSS and vanilla JavaScript**.

**Live demo:** https://hends3368-cpu.github.io/reda-online-shop/

## Features

- Home page with a Swiper slider, category boxes, hot deals and product sections
- Products loaded from `products.json` (electronics, phones, home appliances)
- Shop page with category filter, max price filter and sorting
- Side cart with quantity control and total price (saved in localStorage)
- Favourites list with counter in the header
- Search by product name and category
- Checkout page with order summary and billing form (can send orders to Google Sheets with Google Apps Script)
- Responsive design for mobile, tablet and desktop

## Pages

| Page | Description |
| --- | --- |
| `index.html` | Home page |
| `shop.html` | All products with filters |
| `checkout.html` | Order summary and billing details |

## Tools

HTML5, CSS3, JavaScript (ES6), Swiper.js, Font Awesome, Google Fonts
